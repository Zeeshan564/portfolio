## 🛠️ Personalizing Your Information (Placeholders)

You can easily replace the placeholders in `index.html` with your actual links and details:

1. **Email**:
   Search for `zeeshan.aziz.contact@example.com` in `index.html` and replace it with your personal or student email (e.g. `zeeshan@gmail.com`).

2. **LinkedIn & GitHub**:
   Search for `https://linkedin.com/in/placeholder-zeeshan-aziz` and `https://github.com/placeholder-zeeshan-aziz` and replace them with your actual profile links.

3. **CV / Resume**:
   Drop your PDF resume into the `assets/` folder as `Zeeshan_Aziz_CV.pdf`.

4. **Profile Photo**:
   Drop your picture into `assets/profile.jpg` and update the avatar placeholder container in the Hero Section.

## 🚀 Free Deployment Guide (2 Minutes)

### Option A: GitHub Pages (Recommended)
1. Initialize a git repository:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of portfolio"
   ```
2. Create a new repository on your GitHub account named `portfolio` or `<your-username>.github.io`.
3. Push your code:
   ```bash
   git remote add origin https://github.com/<your-username>/<your-repo-name>.git
   git branch -M main
   git push -u origin main
   ```
4. In GitHub Settings → **Pages**, select branch `main` and root `/`. Your site will be live at `https://<your-username>.github.io/portfolio`!

### Option B: Vercel or Netlify
1. Drag and drop the `zeeshan-portfolio` folder directly into [Vercel](https://vercel.com) or [Netlify Drop](https://app.netlify.com/drop).
2. It deploys automatically with a free SSL domain in under 30 seconds!
